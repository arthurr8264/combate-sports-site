# Combate Sports — site (GitHub Pages)

Versão estática da loja: home, catálogo com filtros, página de produto com cor e tamanho, sacola e pedido pelo WhatsApp.

- Catálogo: `data/catalogo.json` (peças, cores, tamanhos, estoque e dados da loja).
- Fotos: `img/produtos/`. Logo: salve `img/logo.png` e troque o texto da marca na constante `LOGO` em `js/app.js`.
- Este repositório é gerado pelo projeto completo (com painel e banco de dados) com `npm run pages`. Edite as peças lá e gere de novo.
